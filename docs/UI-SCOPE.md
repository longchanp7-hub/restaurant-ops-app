# UI Scope — ホーム画面

## 現時点で確定している方針

- 縦型スマートフォンを主対象にする。
- ホーム画面はスマートフォンのホーム画面のような構成にする。
- 機能は色分けしたブロック（タイル）で表示する。
- 一見して多機能に見えるが、操作は直感的にする。
- 各ブロックは追加・非表示・並べ替えができる。
- 店舗の業種・業態・担当者ごとに、必要な機能だけホームに残せる。
- 各機能の詳細画面・データ構造・外部連携は、ホームUI確定後に設計する。

## 現在の初期ブロック

1. 売上・経営分析
2. シフト・勤怠管理
3. 発注・在庫管理
4. 会計・経費管理
5. スタッフ管理
6. タスク・業務管理
7. レポート・分析
8. AIアシスタント
9. 通知・アラート

## ホーム画面で実装済み

- 編集ボタン
- 長押しで編集モードへ移行
- ドラッグによる並べ替え
- ブロックの非表示
- 非表示ブロックの再追加
- 配置状態の端末内保存
- モバイル向けレスポンシブ表示

## 今は作り込まないもの

- 各ブロックの詳細機能
- POS・会計・勤怠・在庫サービスとのAPI連携
- ログイン・権限管理
- 店舗データベース
- AIの実データ分析
- 通知基盤
- 課金・契約管理

この文書は、以後の開発でホームUIの方針を崩さないための基準として使う。
