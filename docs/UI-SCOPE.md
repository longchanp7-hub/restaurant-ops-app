# UI Scope — ホーム画面

## 現時点で確定している方針

- 縦型スマートフォンを主対象にする。
- 見た目と操作感は **iPhoneホーム画面を強く意識した4列レイアウト** にする。
- 背景は淡いピンク〜ベージュ〜モーヴの抽象的なiOS風壁紙。
- 業務アプリもSNSアプリも同じ正方形アイコンサイズに揃える。
- アイコンの下に機能名を表示し、未確認件数は赤丸バッジで表示する。
- **下部Dock／検索ピル／ページドットは廃止。**
- AI、LINE、カレンダー、設定も通常のホームアイコンとして同じ4列グリッドへ統合する。
- ホーム上の全アイコンは長押しで編集モードに入り、ドラッグで並べ替えできる。
- 不要なアイコンは編集モードで非表示にでき、後から「機能を追加」でホームへ戻せる。
- まず見た目と操作感を作り込み、各機能の詳細画面や外部連携方法は後から決める。

## アイコン方針

- 業務アイコンは各業務を識別しやすい専用SVG。
- SNS系は各サービスを識別しやすい見た目。
- アプリアイコン本体はA案を採用中。
