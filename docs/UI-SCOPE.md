# UI Scope — ホーム画面

## 現時点で確定している方針

- 縦型スマートフォンを主対象にする。
- 見た目と操作感は **iPhoneホーム画面を強く意識した4列レイアウト** にする。
- ダーク系のiOS風壁紙、ガラス調のドック、アプリアイコンの下に機能名を表示する。
- 未確認件数はiPhone風の赤い丸バッジで表示できるようにする。
- 長押しで編集モードへ入り、ドラッグで並べ替え、不要な機能は非表示にできる。
- 非表示の機能は「機能を追加」からホームへ戻せる。
- まず見た目・操作感を作り込み、各機能の詳細画面や外部連携方法は後から決める。
- LINE / Instagram / Facebook / X / TikTok の接続方法は未確定。現段階はホーム上の入口だけを作る。
