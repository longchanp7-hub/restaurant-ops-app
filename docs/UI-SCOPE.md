# UI Scope — ホーム画面

## 現時点で確定している方針

- 縦型スマートフォンを主対象にする。
- 見た目と操作感は **iPhoneホーム画面を強く意識した4列レイアウト** にする。
- 背景は最新iOSを連想させる、淡いピンク〜ベージュ〜モーヴの抽象的な曲線壁紙。
- 業務アプリもSNSアプリと同じ正方形アイコンサイズに揃える。
- アイコンの下に機能名を表示し、未確認件数は赤丸バッジで表示する。
- ホーム上の全アイコンとDockの全アイコンは長押しで編集モードに入り、揺れる。
- ホーム内・Dock内の並べ替えだけでなく、**ホーム⇄Dockのドラッグ移動**にも対応する。
- Dockは4個。満杯のDockへホームアイコンを落とした場合は、落とした位置のDockアイコンと入れ替える。
- 不要なアイコンは編集モードで非表示にでき、後から「機能を追加」でホームへ戻せる。
- まず見た目と操作感を作り込み、各機能の詳細画面や外部連携方法は後から決める。

## アイコン方針

- 上3列の業務アイコンは単純な線画ではなく、各業務を識別しやすい専用SVGにする。
- SNS系は各サービスを識別しやすい見た目にする。
- アプリアイコン本体はA案を採用中。
