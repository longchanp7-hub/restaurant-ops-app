# 飲食店運営アプリ — ホームUI MVP

飲食店の総合業務管理アプリ用の、ホーム画面UIの最小プロトタイプです。

## 現在実装している範囲

- スマートフォンのホーム画面のような機能ブロックUI
- 9個の初期ブロック
  - 売上・経営分析
  - シフト・勤怠管理
  - 発注・在庫管理
  - 会計・経費管理
  - スタッフ管理
  - タスク・業務管理
  - レポート・分析
  - AIアシスタント
  - 通知・アラート
- 編集モード
- ドラッグによる並べ替え
- 不要ブロックの非表示
- 非表示ブロックの再追加
- 設定を localStorage に保存
- モバイルファーストのレスポンシブUI

## 今は実装しない範囲

各ブロックの詳細画面・データ連携・認証・POS/会計/勤怠/在庫API連携などは、ホームUIを確定した後に設計します。

## 起動方法

依存関係はありません。`index.html` をブラウザで開くだけで動きます。
GitHub Pagesにもそのまま配置できます。
