# 飲食店運営アプリ — ホームUIプロトタイプ

飲食店の経営・現場管理をまとめる総合運営アプリです。
現在は**機能の中身より先に、iPhoneホーム画面のような見た目と操作感を作り込む段階**です。

## 現在のホームUI

- ダーク系iOS風の背景
- 横4列のアプリアイコン
- アイコン下に機能名
- iPhone風の赤い件数バッジ
- ガラス調の4アイコン固定ドック
- 長押しで編集モード
- ドラッグで並べ替え
- 不要アイコンの非表示
- 非表示アイコンの再追加
- localStorage に並び順・非表示状態を保存

## ホームグリッド

売上 / シフト / 在庫 / 会計 / スタッフ / タスク / レポート / 通知 /
予約 / 顧客 / メニュー / ヘルプ / ホームページ / Instagram / Facebook / X / TikTok

## 固定ドック

AIアシスタント / LINE / カレンダー / 設定

SNS系は現時点では入口のUIのみです。
外部アプリ起動型・管理ハブ型など、実際の連携方式は後で決めます。

## バッジについて

現在表示する件数はUI確認用のデモ値です。実際の未読件数とは連携していません。
